# 实验 S2：ETF 动量轮动（月度，21 日动量，持有最强 1 只）

- 日期：2026-09-01
- 命令：`python main.py s2`
- 池子：沪深300ETF / 中证500ETF / 证券ETF / 黄金ETF / 纳指ETF（交易日历对齐，2016-08 起）
- 规则：每月末收盘算各 ETF 近 21 日涨幅，次月首个交易日开盘切到最强者；最强者涨幅 ≤ 0 则空仓
- 引擎：新写的组合权重引擎（quant/portfolio.py），ETF 免印花税，佣金+滑点照收

## 结果（2016-08-08 ~ 2026-08-31，2443 交易日）

| 指标 | 轮动策略 | 沪深300ETF 买入持有 |
|---|---|---|
| 总收益率 | **+150.8%** | +61.1% |
| 年化收益率 | **+9.95%** | +5.04% |
| 年化波动率 | 24.4% | 16.8% |
| 夏普比率 | **0.51** | 0.38 |
| 最大回撤 | -39.7% | -38.5% |
| 交易回合/胜率 | 77 / 53% | - |

持仓时间分布：纳指ETF 37%、证券ETF 24%、黄金ETF 20%、中证500 9%、沪深300 仅 1%。

## 结论与教训

1. **收益主要来自"换资产"而不是"挑股票"**：2016-2026 真正的趋势在美股和黄金，
   轮动机制自动把仓位送了过去（A 股宽基几乎没拿过）。动量策略的本质是
   "承认自己不知道谁会涨，只跟着已经涨的走"。
2. **回撤没有改善**（-39.7% vs -38.5%）：2022 股债金三杀、2024 初微盘崩盘传导，
   池内资产相关性在危机中趋于 1，"轮动躲熊市"在系统性危机里失灵。
   想降回撤要靠仓位管理（如波动率目标），不是靠换标的。
3. **换手成本可承受**：月度调仓+每年约 8 次回合，成本拖累约 1%/年以内——
   这就是为什么散户策略应该从"月度级轮动"开始而不是"日线级别打切换"。
4. **未做的检验（诚实声明）**：本结果含参数选择（21日/月度/top1 均为惯例值而非扫描所得），
   且池子构成本身有"后见之明"嫌疑（纳指、黄金 2016-2026 表现好是已知的）。
   下一步应做：lookback 敏感性、滚动样本外、扩池子检验。
