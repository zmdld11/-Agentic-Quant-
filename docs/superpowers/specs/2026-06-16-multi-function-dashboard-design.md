# 多功量化投研看板 v2 架构设计

日期: 2026-06-16

## 目标

将单页看板升级为多功能量化投研平台，新增主页、双股同步率计算、官媒报道查看。加入首页搜索动画过渡。

## 整体架构

```
主页 (无标题栏)                        功能页 (有标题栏+标签)
┌──────────────────┐          ┌──────────────────────────────────┐
│                  │          │ 📊标题(点击回主页) [主页][单股][双股][报道]│
│  标题 + 介绍     │          ├──────────────────────────────────┤
│                  │  点击卡片  │                                  │
│ ┌────┐┌────┐┌───┐│ ──────▶  │  对应功能的内容区                  │
│ │单股││双股││官媒││          │                                  │
│ │分析││同步││报道││          └──────────────────────────────────┘
│ └────┘└────┘└───┘│
│                  │
└──────────────────┘
```

- 点击标题文字可回主页
- 标题栏仅在功能页显示
- 标签切换不刷新页面（纯前端 SPA）

## 前端路由

纯前端状态切换，无 URL 路由。用一个 `activeTab` 变量控制：

| 状态 | 显示内容 |
|------|---------|
| `home` | 主页：标题、介绍、三张功能入口卡片 |
| `single` | 单股分析：搜索框 + K线图 + 指标 + AI报告 |
| `dual` | 双股同步：两个输入框 + 相关性分析 + AI解读 |
| `news` | 官媒报道：日期选择 + 分类新闻列表 |

## 单股分析 — 搜索动画

三种状态：

1. **init（初始）** — 页面中央大搜索框(w 360px) + 蓝色查询按钮，灰字提示
2. **loading（查询中）** — 搜索框下方出现加载动画
3. **success（成功）** — 搜索框缩小上移至标签栏下方，标题栏 + 结果区从下方滑入展开 (0.5s ease-out)
4. **error（失败）** — 红色提示浮在搜索框下方，框不动，可重新输入

已查询成功后（标题栏已显示），再次搜索新代码时不再触发过渡动画，仅原地刷新数据。

点击标题栏文字 → 回到主页（home 态）。

## 双股同步

**布局：**
- 两个并排输入框 + 分析按钮 + 时间段切换
- 上方指标卡片：Pearson 相关系数、同步率判定
- 走势叠加图（ECharts，归一化价格） + 散点回归图
- 可选：AI 解读文案

**后端计算：**
- 新增 API：`POST /api/sync`，入参 `{symbol_a, symbol_b}` 或查询参数
- 两只股票各取 250 根 K 线，对齐日期
- pandas 计算：Pearson 相关系数、归一化价格、线性回归斜率
- 同步放回前端画图

**AI 解读（可选）：**
- 复用现有 LLM 接口，传入同步率数据 + 个股基本信息
- 不调用则不消耗 token

## 官媒报道

**布局：**
- 日期切换按钮组（今天 / 前一天 / 后一天）
- 类别分区：宏观政经 / 行业动态 / 政策文件
- 每条新闻显示来源 + 标题 + 时间戳

**数据：**
- `akshare.news_report_js()` — 决策报告/政策文件
- `akshare.stock_info_global_em()` — 全球宏观快讯（已有）
- `akshare.stock_info_global_sina()` — 新浪全球政经（已有）
- 按当天日期过滤，前端分类展示

**不持久化：** 内存缓存当天数据，过期自动释放。不写数据库。

## 性能考量

- 2C2G 服务器：所有计算均为 pandas 轻量运算，无深度学习
- 双股同步：两次 Baostock 查询（各 250 条）+ pandas corr，耗时 < 2 秒
- 官媒报道：单次 akshare 请求 + 过滤，耗时 < 3 秒
- 全部数据在内存缓存，不写磁盘
